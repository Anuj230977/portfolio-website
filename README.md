# 🌐 Anuj Jadhav — Portfolio Website

Welcome to my personal portfolio website!

- Contact information (email, LinkedIn, GitHub)

## 🖥️ Live Preview

You can view the HTML page locally by downloading or cloning this repo and opening `index.html` in your browser.

## 📂 Project Structure

```
portfolio-website/
├── index.html     # Main portfolio page
├── style.css      # Stylesheet for the portfolio
```

## 🛠️ Usage

1. **Clone/download** this repo:
   ```sh
   git clone https://github.com/Anuj230977/portfolio-website.git
   ```
2. Open `index.html` in your favorite browser.

No build/tools are necessary—this is a 100% static website.

## ✏️ Customize
